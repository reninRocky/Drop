# LAN File Transfer Tool 🚀

A fast, cross-platform file sharing solution for your Local Area Network. Share files between your PC, Phone, and other devices instantly without any internet connection.

![Project Banner](frontend/src/assets/hero.png)

## ✨ Features

- **Real-time Sharing**: Instant notifications when files are uploaded or devices join.
- **Cross-Platform**: Works on Web, Windows, and Android.
- **No Internet Required**: Works entirely over your local Wi-Fi/Ethernet.
- **Drag & Drop**: Intuitive interface for easy file uploads.
- **Auto-Cleanup**: Automatically deletes old files to save space.
- **Responsive Design**: Beautiful UI that works on all screen sizes.

## 🏗️ Project Structure

The project is divided into four main components:

- **[Backend](./backend)**: Node.js/Express server with Socket.io.
- **[Frontend](./frontend)**: React 19 application built with Vite and Tailwind CSS 4.
- **[Mobile App](./mobile-app)**: Android wrapper using Capacitor.
- **[Windows App](./windows-app)**: Desktop application using Electron.

## 🚀 Quick Start

To get the project running locally:

1. **Start the Backend**:
   ```bash
   cd backend
   npm install
   npm run dev
   ```

2. **Start the Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Open in Browser**:
   Visit `http://localhost:5173` to start sharing files!
